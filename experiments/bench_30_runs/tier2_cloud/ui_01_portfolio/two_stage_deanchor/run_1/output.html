### Architectural Blueprint & System Design This greenfield implementation follows a strict **Clean Architecture** (Ports & Adapters) paradigm, separating concerns into three distinct layers: 1. **Domain Layer**: Pure business entities, value objects, and invariant-enforcing logic. Free from framework dependencies. 2. **Application Layer**: Use cases, state machines (handling `ThemeSwitched`, `ContactFormSubmitted`, and UI visibility transitions), and operational ports. 3. **Infrastructure & Presentation Layer**: Modern React 18+ components using TypeScript, Tailwind CSS for styling, Context API for state management, and robust API adapters for secure POST routing. --- ### File Directory Structure ``` src/ ├── domain/ │ ├── entities.ts │ └── invariants.ts ├── application/ │ ├── state-machine.ts │ └── use-cases.ts ├── infrastructure/ │ ├── api-client.ts │ └── storage.ts └── presentation/ ├── context/ │ └── ThemeContext.tsx ├── components/ │ ├── Header.tsx │ ├── Hero.tsx │ ├── SkillsGrid.tsx │ ├── ProjectCard.tsx │ ├── BlogCard.tsx │ ├── ContactForm.tsx │ ├── ScrollToTopButton.tsx │ └── Footer.tsx └── App.tsx ``` --- ### Layer 1: Domain Models & Invariants (`src/domain/`) #### `src/domain/entities.ts` ```typescript export interface Skill { name: string;
