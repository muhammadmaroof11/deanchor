# Architectural Review & Greenfield Refactoring ## 1. Critical Issues Identified in Draft Implementation ### Legacy Patterns Retained: - **Legacy CSS class naming**: `primary-bg-btn`, `secondary-bg-btn` instead of modern BEM or utility-first patterns - **Anchored component structure**: Fixed navigation with hardcoded links rather than dynamic routing - **Inconsistent state management**: React hooks used but not integrated into a proper state container pattern ### Core Domain Functions Not Preserved: - **Theme switching logic** is incomplete - missing persistence and context integration - **Scroll spy functionality** removed from original implementation - **AOS animations** (Animate On Scroll) completely omitted - **Responsive navigation behavior** simplified to basic toggle without proper mobile UX patterns ## 2.
