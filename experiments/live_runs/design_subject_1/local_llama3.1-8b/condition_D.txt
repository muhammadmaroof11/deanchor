**CloudMetrics System Dashboard Refactored**

### Architecture Overview

The refactored code will be based on a modern web development architecture that separates concerns into smaller, independent components. This approach will make it easier to maintain, update, and scale the application.

**Components**

1. **Frontend**: Written in HTML, CSS, and JavaScript, using a framework like React or Vue.js for building reusable UI components.
2. **Backend**: Built using a Node.js server, with Express.js as the web framework, and a database like MongoDB or PostgreSQL for storing data.
3. **API Gateway**: Handles incoming requests, authenticates users, and routes requests to the appropriate backend services.
4. **Data Services**: Responsible for fetching and processing data from various sources, such as AWS CloudWatch or Prometheus.

**Dashboard.js**
```jsx
import React, { useState, useEffect } from 'react';
import Sidebar from './Sidebar';
import Card from './Card';
import Table from './Table';

const Dashboard = () => {
  const [data, setData] = useState({});

  useEffect(() => {
    // Fetch data from API
    fetch('/api/dashboard')
      .then(response => response.json())
      .then(data => setData(data));
  }, []);

  return (
    <div className="main">
      <div className="header">
        <h1>Infrastructure Telemetry</h1>
        <button style={{ background: '#2563eb', color: 'white', padding: '8px 16px', border: 'none', borderRadius: '4px' }}>
          Refresh Data
        </button>
      </div>
      <div className="cards">
        <Card title="CPU Utilization" value="68.4%" subtitle="↑ 4.2% from last hour" />
        <Card title="Memory Allocation" value="24.8 / 32 GB" subtitle="77.5% capacity" />
        <Card title="Active I/O Operations" value="1,420 ops/s" subtitle="Normal latency 1.8ms" />
      </div>
      <h2>Active Node Clusters</h2>
      <Table data={data} />
    </div>
  );
};

export default Dashboard;
```
