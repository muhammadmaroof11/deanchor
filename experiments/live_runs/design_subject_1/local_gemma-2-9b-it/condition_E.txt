**UI Structure**

1. **Dashboard:**
   * A central hub providing a high-level overview of system health and performance.
   * Key visualizations:
     * Overall system status (e.g., green for healthy, yellow for warning, red for critical)
     * Uptime graph
     * Summary of CPUUtilization, MemoryAllocation, and ActiveIOOperations across all nodes.
   * Quick access links to drill down into specific areas (Overview, Instances, Storage, Alerts).

2. **Overview:**
   * A more detailed view of the system's current state.
   * Information:
     * NodeCluster details (number of nodes, regions, etc.)
     * Status of each node (online, offline, degraded)
     * Detailed CPUUtilization and MemoryAllocation charts for each node
     * ActiveIOOperations statistics

3. **Instances:**
   * A list of all running instances (grouped by NodeCluster, Region, or other relevant criteria).
   * Information for each instance:
     * Instance ID
     * Status (running, stopped, failed)
     * Resource utilization (CPU, memory)
     * Links to detailed instance logs and monitoring

4. **Storage:**
   * Overview of storage resources (e.g., disk space, network bandwidth).
   * Information:
     * Total storage capacity and available space
     * Storage utilization trends
     * Alerts for low disk space or network congestion

5. **Alerts:**
   * A log of system events and alerts.
   * Filtering and sorting options to focus on specific types of alerts.
   * Options to acknowledge and dismiss alerts.

6. **Settings:**
   * Configuration options for the system (e.g., update schedules, notification preferences).

7. **Infrastructure:**
   * Detailed information about the underlying infrastructure (e.g., network topology, server specifications).
