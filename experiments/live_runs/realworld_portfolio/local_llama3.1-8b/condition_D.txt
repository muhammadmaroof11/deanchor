**JavaScript Structure**

```javascript
// script.js
// Import dependencies
import './styles.css';

// Set up Clarity Analytics
window.clarity = window.clarity || function() {
    (window.clarity.q = window.clarity.q || []).push(arguments);
};

// Initialize Clarity Analytics
window.clarity('track', 'PageView');

// Add event listeners for preloader
document.getElementById('preloader').addEventListener('load', () => {
    document.getElementById('preloader').style.display = 'none';
});

// Add event listeners for navigation menu
document.addEventListener('DOMContentLoaded', () => {
    const navbar = document.getElementById('navbar');
    const links = navbar.querySelectorAll('a');

    links.forEach((link) => {
        link.addEventListener('click', (e) => {
            e.preventDefault();
            const target = document.querySelector(link.href);
            target.scrollIntoView({ behavior: 'smooth' });
        });
    });
});
```

**Modern Architecture**

This refactored code follows a modern architecture that separates concerns and uses modern web development techniques. Here are some key changes:

1.  **Separation of Concerns**: The HTML, CSS, and JavaScript code are separated into different files, making it easier to maintain and update each component individually.
2.  **CSS-in-JS**: The CSS code is written in a CSS-in-JS style, using a CSS file to define the styles. This approach makes it easier to manage complex styles and layouts.
3.  **JavaScript Modules**: The JavaScript code is written using ES6 modules, which allows for a more modular and maintainable codebase.
4.  **Clarity Analytics**: The Clarity Analytics script is added to the HTML file, and the JavaScript code sets up the analytics using the Clarity API.
5.  **Preloader**: The preloader is added to the HTML file, and the JavaScript code adds event listeners to hide the preloader when it finishes loading.
